# Что реализовано

Краткая сводка реализованной функциональности выпускной квалификационной
работы — веб-платформы для взаимодействия заказчиков и исполнителей
IT-проектов.

## Аутентификация и роли

- Регистрация и вход по email и паролю, JWT-аутентификация.
- Три роли: заказчик (CUSTOMER), исполнитель (CONTRACTOR), администратор
  (ADMIN).
- Защита маршрутов: `JwtAuthGuard` (проверка токена) и `RolesGuard`
  (разграничение по ролям).
- Блокировка аккаунтов: заблокированный пользователь не может войти,
  видит причину и срок блокировки; авто-разблокировка по истечении срока.

## Профиль пользователя

- Просмотр и редактирование профиля: имя, «о себе», навыки.
- Смена email (с подтверждением паролем) и смена пароля.
- Индикатор надёжности пароля, индикатор заполненности профиля.
- Личная статистика и рейтинг по полученным отзывам.

## Проекты

- Создание проекта заказчиком с выбором категории и диапазона бюджета.
- Каталог проектов: фильтры по статусу и категории, поиск, сортировка,
  пагинация, режимы «Все / Мои / Я откликнулся».
- Детальная страница проекта, действия владельца: отмена и завершение.
- Статусная модель: `OPEN → IN_WORK → DONE`, отдельно `CANCELED`.

## Отклики

- Отправка отклика исполнителем (цена, срок, сопроводительное сообщение).
- Запрет повторного и собственного отклика, отклик только на `OPEN`.
- Редактирование и удаление своего отклика.
- Просмотр откликов владельцем проекта, принятие и отклонение.
- Принятие отклика — Prisma-транзакция: фиксация исполнителя, перевод
  проекта в `IN_WORK`, отклонение остальных откликов.
- Страница «Мои отклики» для исполнителя.

## Категории и навыки

- Справочник категорий проектов, фильтрация каталога по категории.
- Навыки нормализованы в отдельные таблицы (`Skill`, `UserSkill`),
  автоподсказки при заполнении профиля.

## Отзывы и рейтинг

- Взаимные отзывы заказчика и исполнителя по завершённому проекту.
- Оценка от 1 до 5, средний рейтинг и список отзывов в профиле.

## Уведомления

- Уведомления о событиях: новый отклик, принятие/отклонение отклика,
  завершение проекта, новый отзыв.
- Значок уведомлений в шапке со счётчиком непрочитанных, авто-обновление.

## Администрирование

- Панель администратора: сводная статистика платформы.
- Управление пользователями: список, поиск, фильтры, блокировка,
  смена роли, удаление, детальная карточка.
- Модерация проектов (принудительная отмена, удаление) и откликов.

## Серверная часть

- Модульная архитектура NestJS (9 модулей).
- REST API с документацией Swagger / OpenAPI: описания операций, схемы
  запросов и ответов.
- Валидация входных данных через DTO и `class-validator`.
- Глобальный фильтр исключений, логирование, пагинация.
- Unit- и e2e-тесты ключевой бизнес-логики.

## Клиентская часть

- Next.js (App Router), TypeScript, TailwindCSS, shadcn/ui.
- TanStack Query для серверного состояния, axios-клиент с перехватом 401.
- Состояния загрузки, пустых выборок и ошибок на ключевых страницах.
- Адаптивная вёрстка.

## База данных

- PostgreSQL, 8 таблиц, управление схемой и миграциями через Prisma.
- Сущности: User, Project, Bid, Category, Skill, UserSkill, Review,
  Notification.
